## Documentation mismatch

[README errors](../README.md#errors) says `E_DUPLICATE_REQUEST_IN_PROGRESS` occurs only on re-entry from the command's own `work`. [The exception](../src/errors.ts#L16) documents re-entry from `work` or policies, and [the pending insert](../src/receipts.ts#L371) precedes `authorizeExecute`, so re-entry from `authorizeExecute` also reports in-progress. This is an open README defect, not an intentional boundary. US-GUARD-01 states the source behavior; the README wording is not corrected by this catalogue.
